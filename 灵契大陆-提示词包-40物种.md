## 三、生成纪律

| 规则 | 说明 |
|---|---|
| 一次只改一个变量 | 改色或改形分开跑，否则分不清是哪个导致的 |
| 同族必须图生图 | 二阶三阶必须以本物种一阶为 `image1`，禁止纯文生 |
| 重试上限 | 同一提示词最多 3 次，第 4 次必须改描述 |
| 失败处理 | 先简化主体（减特征件），再拆件生成 |
| 朝向检查 | 生成后统一检查朝向，朝左的批量镜像 |
| 版权检查 | 逐张确认无现有 IP 特征，可疑的重新生成 |

### 反写实陷阱（s14 实测，最容易踩）

要求"岩石、甲片、鳞、毛发"这类**材质**时，AI 会把整张图拉向写实绘本——身上长出毛发线、肌肉线、皮肤褶皱，线要素从 30 条涨到 100+ 条，与同批平涂图直接脱节。

**写法**：
- 写 `large smooth flat stone plates, each plate a single flat colour, no cracks, no texture`，**不要**写 `rocky texture / cracked stone / layered rock detail`；
- 负向固定加 `no fur lines, no muscle definition lines, no skin wrinkles, no body detail lines, extremely minimal linework under thirty lines total`；
- 已经画花了不要重新生成，用**图生图**（`input_fidelity: high`）只下"去线 + 改色"指令，保住结构。

## 四、后处理命令

```bash
# 1. 抠图（纯白底 → 透明）
python art_asset_tools.py keyout <img> --color "#FFFFFF"

# 2. 裁掉透明边 + 统一到 256

python art_asset_tools.py check <dir>

# 4. 接触表（三道一致性检查）
python art_asset_tools.py sheet <dir>
```

## 五、批次计划

| 批次 | 内容 | 图数 | 验收标准 |
|---|---|---|---|
| B0 | 三属性基准各 1 只（火/水/龙的一阶） | 3 | 画风锚点 11 项全过，用户确认 |
| B1 | 13 只一阶（补齐全部属性） | 13 | 与 B0 同批并排无风格漂移 |
| B2 | 剩余 27 只一阶 | 27 | 40 只涂黑剪影两两可辨 |
| B3 | 全部二阶（图生图） | 40 | 体轴或附肢必须变化 |
| B4 | 全部三阶（图生图） | 40 | 门类跃迁，轮廓复杂度 +1 |
